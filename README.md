# 📌 Overview

**Namma Shaale Inventory** is a smart digital asset auditing and inventory management application designed for **government primary and secondary schools**.

Schools receive valuable resources such as:

- 🏈 Sports Kits
- 🔬 Lab Equipment
- 💻 Tablets
- 📚 Educational Resources

However, there is often **no proper system to track the condition and usage** of these assets.

This application helps teachers and school administrators:

✅ Register assets  
✅ Track asset condition  
✅ Log issues and damages  
✅ Monitor repair requests  
✅ Maintain accountability for government-funded resources  

---

# 🎯 Problem Statement

Government schools frequently face challenges such as:

- Broken tablets discovered months later
- Missing sports equipment
- Damaged laboratory instruments
- No centralized asset tracking system
- Difficulty auditing school inventory

This leads to:

- Poor resource utilization
- Reduced educational quality
- Lack of accountability

---

# 💡 Solution

Namma Shaale Inventory acts as a:

# 🧾 “Digital Asset Auditor”

The application enables schools to digitally manage and audit all institutional assets efficiently.

Teachers can:

- Scan and register assets
- Monitor monthly asset health
- Upload photos of asset conditions
- Generate repair requests
- Maintain issue logs

---

# 🚀 Features

## 📦 Asset Register
Add and manage school assets including:

- Asset Name
- Serial Number
- Category
- Asset Photo
- Purchase Details

---

## 🟢 Monthly Health Check

Track the condition of every asset using:

| Status | Meaning |
|---|---|
| 🟢 Green | Working Properly |
| 🟡 Yellow | Needs Attention |
| 🔴 Red | Broken / Damaged |

Teachers can quickly update multiple assets during periodic inspections.

---

## 📝 Issue Log

Maintain records of issues such as:

- Lost items
- Damaged equipment
- Misuse reports
- Missing sports kits

Each issue contains:

- Date
- Description
- Reason
- Associated Asset

---

## 🔧 Repair Request System

Assets needing repair are automatically tracked and listed for:

- SDMC review
- Maintenance scheduling
- Replacement planning

---

## 📊 Dashboard Analytics

Professional dashboard displaying:

```text
Total Assets: 50
Working Assets: 40
Needs Repair: 5
Broken Assets: 5
```

---

## 📷 CameraX Integration

Capture and store asset condition photos directly from the app.

Useful for:

- High-value equipment
- Damage documentation
- Audit transparency
